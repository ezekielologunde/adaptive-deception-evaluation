## Candidate distinction, not novelty clearance

The actionable question is whether a deployable acquisition rule under unknown cross-policy memory transfer can retain useful information while avoiding measurable damage to subsequent deployment. Known-model exact planning is an oracle comparator. A practical approximation would need an explicit accuracy/computation or safety/selection benefit over matched prior methods, with independent environments and misspecification tests.

Reject these proposed claims now: first active policy selection; first safe evaluation; first memory-aware planning; first carryover-aware design; a new regret decomposition; superiority demonstrated solely against uniform or stationary sampling. The native simulator order test is a falsification gate for practical relevance, not a novelty certificate.

Before implementation of a proposed new method, require (1) a written distinction from state-augmented Bayesian planning and switchback design, (2) a matched baseline using the same observations/model knowledge, (3) a held-out test and a failure criterion, and (4) a contribution beyond a different cyber dataset. Preserve negative findings rather than turning each screening step into another manuscript.

## Additional overlap checked during reference execution

- [Mintz et al., Nonstationary Bandits with Habituation and Recovery Dynamics, Operations Research 2020](https://pubsonline.informs.org/doi/10.1287/opre.2019.1918). Publisher abstract reviewed. ROGUE models include action-induced loss and recovery of efficacy, parameter estimation, and UCB/exploration algorithms. Recovery or habituation by itself is not a distinguishing contribution. Full assumptions must be reviewed before implementing a comparator.
- [Ben Naveed et al., Trajectory Planning for Safe Dual Control with Active Exploration, 2026 preprint](https://kalebbennaveed.github.io/tro_dual_gtk/Dual_gk_TRO.pdf). Author page labels it under review. Inspected formulation and budget guarantee, PDF pp. 3, 6-8, and limitations p. 17. It combines robust backup planning, informative candidates, and an exploration-cost budget. Assumption 2 requires perfect state observation; parameters are bounded in a known set. The limitations discuss time-varying parameters and planned versus realized information reduction. This directly overlaps generic safe information acquisition. Hidden state distinguishes an assumption, not automatically a new method or result.
- [Chandak et al., OPEN, NeurIPS 2022](https://papers.nips.cc/paper/2022/hash/3bf80b34f731313b8292f4578e820c90-Abstract-Conference.html). Primary proceedings abstract rechecked. It already treats action-dependent change under a higher-order stationarity assumption. Prior limited interface controls in this repository do not constitute full reproduction. Do not misstate active nonstationarity as unstudied.

These additions further narrow permissible claims. None establishes that the remaining hidden-conditioning question is unexplored. No claim of an exhaustive search is made.
