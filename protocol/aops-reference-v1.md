# A-OPS reference execution protocol

Frozen before reference outcomes are collected. This reproduces the authors' algorithm on their cartpole example, not a proposed new algorithm or cyber evaluation.

Upstream: google-deepmind/active_ops, commit 5c7b24515adadbaf89feb84232190bad96221c04. Import unchanged modules and restricted-load the previously audited data. Match notebook priors, 50 policies, four agents, FQE initialization, exploration coefficient 5, Adam learning rate .001, 1,000 optimizer iterations per update, and agent iteration order. Rewards are sampled with replacement from the fixed public samples; regret is relative to their empirical means, not known population values.

Documented deviations: headless script instead of notebook; isolated Python 3.9.25 CPU environment; seed Python random and TensorFlow as well as NumPy with 805+experiment (notebook seeds NumPy only); convert dict items to list for policy sampling; cache action distances once rather than recomputing them per experiment. Do not reduce optimizer iterations to improve speed or results. Pin resolved runtime dependencies, including a compatible protobuf version. Plotting/notebook dependencies are not needed for the runner.

First verify the Gaussian posterior against a direct NumPy covariance calculation with repeated observations, and verify the UCB decision. Pilot: experiment 0, five rounds. Retain it separately. If the measured pilot permits a ten-experiment, 100-round run within an estimated 30 local CPU minutes, run experiments 1 through 10 with 100 rounds each. Otherwise run experiments 1 through 3 with 20 rounds each and record why the full scale was deferred. This is a resource feasibility rule, not outcome-based selection. Never label either reduced run as full Figure 14 reproduction (100 experiments, 100 rounds).

Save policy identities, FQE regret, each selected arm/reward/recommended arm and regret, timings, source and protocol hashes, and environment versions. Retain failures. Independently recompute every reported regret from public data; verify rewards belong to the selected policy, action-distance kernel and GP posterior, and source hashes. Run one fresh-process repeat of the pilot and compare decisions/rewards/regrets with a stated float tolerance. Report results descriptively, with per-experiment paired differences and standard errors when there is more than one run. No significance or novel-method claim follows from this reference run.
